# 七巧木作

把实体七巧板的取板、观察图谱、转动和拼合搬到浏览器。当前默认是 **8 张具象图谱的木质样片**：小木盘、小帐篷、小房子、小帆船、小火箭、小石桥、小松树和小鸟。原有 100 题保留为经典题库，可在「家长的小抽屉」切换；本次并未将全部 100 题替换为木质主题内容。

## 体验

- 儿童默认「一步一步玩」：前 3 张补 1 块，第 4～7 张补 2 块，第 8 张补 3 块并引入旋转。已摆木块锁定，帮助逐步减少。
- 「大朋友挑战」从第一张起使用全部七块，不预置拼板。
- 榉木纹理、彩色漆面、木框收纳盘、纸质图谱、作品小册、取放阴影及短促木质音效。
- Rive 实际驱动小手示范、完成印章、翻页和小鸟反馈；运行素材随应用本地部署。
- 拖拽、45° 旋转、按阶段开放的翻面、撤销、重摆和分级提示。只对齐可见轮廓和已摆木块，不吸附隐藏答案。
- 自动保存局面与完成记录，支持 iPad 横竖屏布局、大触摸按钮和减少动态效果设置。

本版的学习速度与趣味性仍需要真实儿童试玩校准。浏览器设备模拟已验证，真机 iPad Safari 的手感由体验验收确认。

## 本地开发与检查

```sh
npm install
npm run dev -- --port 5173
npm test
npm run build
```

默认入口 `http://localhost:5173/`。`?level=1&mode=relax&pack=wood` 打开木质渐进第一关；`?level=1&mode=challenge&pack=wood` 打开七块挑战；`?level=1&mode=relax&pack=classic` 打开经典 100 题。

选中木块后可用 Q / E 旋转、F 翻面、方向键微调、Ctrl / Command + Z 撤销；操作限制与当前学习阶段一致。完成判定依据七块板的几何覆盖，接受同形拼板互换和其他合法解法。

## Docker 部署

```sh
docker compose up -d --build --wait
```

默认端口 8080；本机 `.env` 设置 `PORT=8088`，当前访问 `http://localhost:8088/`。如需更改，复制 `.env.example` 为 `.env` 并设置 `PORT`。iPad 与电脑连接同一 Wi-Fi 后，打开 `http://电脑的局域网IP:8088/`。

```sh
docker compose ps
docker compose logs -f
docker compose down
```

构建镜像执行自动测试和生产构建，运行镜像为 Nginx，健康检查 `/healthz`。带哈希的资源长期缓存，HTML、Rive 和木纹素材重新验证。ARM64 / AMD64 使用对应平台基础镜像。Rive 动画和 WASM 随镜像提供，部署不依赖 Rive CLI、账户或在线动画服务。

## 存档

经典题库继续使用 `sevenfold-v1`，木质样片使用独立的 `sevenfold-wood-v1`。两套存档互不覆盖。数据保存在当前浏览器和访问源中；切换域名、端口或设备不会自动同步。无账号、云存档或公开排行榜。

## 内容与素材

- `src/wood-levels.json`：8 张具象图谱和参考解，支持多轮廓。
- `src/levels.json`：保留的经典 100 题。
- `src/geometry.ts`：标准七巧板、变换、对齐和覆盖判定。
- `src/board.ts`、`src/materials.ts`：交互、学习辅助和木质渲染。
- `src/views.ts`、`src/style.css`：玩具桌、图谱、游戏和作品册。
- `src/motion.ts`：Rive 反馈和动画生命周期。
- `animation-src/README.md`：自制 Rive 动画源与重建说明。
- `artifacts/WOOD-ASSETS.md`：木纹来源、完整生成提示词与保存路径。
- `artifacts/VALIDATION.md`：检查记录。

`npm run generate:wood` 可复现木质 8 张图谱，`npm run generate` 重建经典候选题库。正式玩家已有存档时，不应直接替换关卡数据。

经典 100 题的渐进规则继续为：1～3 关 1 块、4～7 关 2 块、8～12 关 3 块、13～18 关 4 块、19～25 关 5 块、26～35 关 6 块、36 关起全部 7 块；第 8 关引入旋转、第 22 关引入翻面。

## 移动端 App 界面（2026-11-16）

界面使用固定顶部栏和底部操作区，图谱、作品册通过底部导航切换。主要说明与辅助文字至少 18px，手机按钮标签 18px、平板 19～20px，弹窗正文 20px；交互文字不再随游戏画布一起缩小。

手机和宽度不超过 900px 的平板竖屏使用上下分布的拼图区与木块盘；横屏使用左右分布。小高度横屏将工具移至右侧，手机七块挑战将六个操作分为两排。安全区域、浏览器动态高度和减少动画设置受到支持。

存档增加布局标记，读取旧局面默认按原横屏布局转换。切换横竖屏时保留目标区域中已摆木块的位置和方向，收纳盘中的木块重新排布；撤销记录同步转换。两套题库原有完成记录继续保留。

## 部署到网站子路径

```sh
npm test
npm run build -- --base=/play/tangram/
```

将 `dist/` 发布到网站的 `/play/tangram/` 静态目录；无尾斜杠入口可重写到该目录的 `index.html`。Phaser 木纹、Rive 动画和 WASM 跟随 Vite 的 `BASE_URL`，不依赖站点根目录。默认不传 `--base` 时仍支持根路径部署。

## Native 导航栏与 WebView 高度

页面使用 Web 实际可用高度（布局视口与未缩放的 visualViewport 取较小值），不会根据物理屏幕高度推测或重复扣除导航栏。窗口、可见视口和父容器尺寸变化时重新等比适配画布；较矮横屏将操作区移至侧边。原生宿主应将 WebView 的实际可视区域设置在导航栏之下；若宿主直接覆盖 WebView 且不更新其视口，网页无法自行得知覆盖区域。
